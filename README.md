# 抽卡模拟器

本软件采用[QT]框架，[python]语言进行构建，实现猫meme主题抽卡

---
## 软件介绍

双击main.exe文件执行，右上角显示祈愿币的数量用于抽卡，左上角【BGM】按钮可控制音乐开关，左侧角【单抽】按钮进行抽卡，当祈愿币数量为0时会提示祈愿币不足（蒸蚌！）。
<br>你还可以点击【抽卡记录】看到自己的本地信息哦<br>
<br>现在请点击【图鉴】，快来看看自己有没有完成全图鉴吧！<br>
<br>究竟是至尊无敌大欧皇，还是来自非洲的哥们：点击【欧非鉴定】查看<br>
<br>再来一次？【重置祈愿币】（试用期免广告中）<br>

---
## 自定义功能

<br>通过同类名文件替换实现自定义抽卡视频和卡面<br>

- 通过替换文件内 01.mp4 文件自定义主界面播放视频
- 通过替换文件内 02.mp4 文件自定义主抽卡视频
- pic文件夹替换图片内自定义✨卡面✨【jpg格式】
- 命名规范参照原本的即可
