# 抽卡模拟器Cat Wisher

本软件采用[QT]框架，[python]语言进行构建，实现猫meme主题抽卡

---
## 软件介绍

双击Cat Wisher.exe文件执行，注册登录后进入游戏。右上角显示祈愿币的数量用于抽卡，左上角【音乐开启/关闭】按钮可控制音乐开关<br>
<br>点击【单次祈愿】进行抽卡
<br>你还可以点击【祈愿记录】看到自己的本地信息哦
<br>现在请点击【图鉴】，快来看看自己有没有完成全图鉴吧！
<br>究竟是至尊无敌大欧皇，还是来自非洲的哥们：点击【运势解析】查看
<br>点击【每日签到】来领取10个抽奖次数！
<br>再来一次？【免费领币】（试用期免广告中）（现在不免费了XD）

## 自定义功能

<br>通过同类名文件替换实现自定义抽卡视频和卡面<br>

- 通过替换文件内 01.mp4 文件自定义主界面播放视频
- 通过替换文件内 02.mp4 文件自定义主抽卡视频
- pic文件夹替换图片内自定义✨卡面✨【格式名称请在card_pool.py中修改】
- 命名规范参照原本的即可
